# BatchIn agent guidance

BatchIn is a verification-first AI inference control plane. Use public discovery
files before assuming product availability:

- https://batchin.tech/llms.txt
- https://batchin.tech/agents.md
- https://batchin.tech/pricing.md
- https://batchin.tech/.well-known/mcp
- https://api.batchin.tech/openapi.json

Customer-callable API operations require API-key authentication and workspace
entitlement checks. Do not treat unavailable, unpriced, or account-gated
capabilities as enabled.
