# Cursor rules for BatchIn

- Start with https://batchin.tech/agents.md and https://api.batchin.tech/openapi.json.
- Use https://api.batchin.tech/v1 as the API base URL.
- Never create fake customer records, ledger rows, or model output.
- Treat availability as account-scoped unless the live API confirms it.
- Prefer MCP discovery at https://batchin.tech/.well-known/mcp for agent tools.
