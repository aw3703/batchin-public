# @batchin/cli

Command-line helper for authenticated BatchIn API checks.

## Install

This package is source-ready. Registry publication must be verified before
installing by package name.

    git clone https://github.com/aw3703/batchin-public.git
    cd batchin-public/packages/cli-ts
    npm install
    npm run build
    node src/cli.js models

Set BATCHIN_API_KEY for account-scoped operations.
